# EPS Connect Releases

Canal público de distribuição do aplicativo **EPS Connect para Windows**.

Este repositório contém apenas os arquivos publicados para instalação e atualização automática do aplicativo. O código-fonte principal do EPS Connect permanece privado.

Arquivos de atualização esperados em cada versão:
- `EPS-Connect-Setup-<versão>-x64.exe`
- `latest.yml`
- `*.blockmap`

Os clientes instalados usam este repositório somente para verificar, baixar e instalar novas versões.
